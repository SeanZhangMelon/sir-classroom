# 看见传播的变化 · SIR 观察实验

面向初中生的数学与生物学跨学科教学网页。

## 在线访问

https://seanzhangmelon.github.io/sir-classroom/

## 课堂操作

播放、暂停、逐日观察、调节速度或拖动时间，比较易感者、感染者、移出者的人数变化与感染人数曲线。

## 数据说明

这是教学用的随机空间 SIR 模拟，不是真实疫情数据。总人数 900，初始感染者 3 人，固定随机种子确保每次播放相同；第 0—51 天对应教材表 1 的 52 个数据。页面包含全部模拟逻辑，不依赖服务器接口或外部素材。

## 维护

编辑根目录 index.html 并提交到 main 分支，GitHub Pages 自动更新。下载 index.html 后也可离线打开。保留仓库与 Pages 设置即可继续使用访问地址。
